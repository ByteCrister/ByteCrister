## 👋 About Me

Hi, I'm **Sadiqul Islam Shakib** — a full-stack developer from **Bangladesh**, currently pursuing my undergraduate degree at **North East University Bangladesh (NEUB)**.

I build complete, production-grade web applications — from designing database schemas and REST APIs to crafting polished, interactive frontends. My work spans real-time systems, AI-assisted tooling, platform management dashboards, and developer utilities.

```text
🔭  Currently building  →  opal-melamine-stock-balancer & BD Travel Spirit ecosystem

📍  Location            →  Bangladesh
```

### 🧭 [BD Travel Spirit — Guide System](https://github.com/ByteCrister/bd-travel-spirit-guide-system)
**Full-stack tour guide management platform for Bangladesh's travel ecosystem**

A role-based SaaS platform where **Guides** and **Assistants** manage tours, bookings, reviews, payments, employees, and real-time support communications. Travelers access a public landing page to discover and book tours.

| | |
|---|---|
| **Live** | [bd-travel-spirit-guide-system.vercel.app](https://bd-travel-spirit-guide-system.vercel.app) |
| **Stack** | Next.js 16 (Beta) · React 19 · TypeScript · MongoDB · NextAuth v5 · Zustand · Stripe · Socket.IO · Cloudinary · Redis · Framer Motion · Recharts · Leaflet |
| **Highlights** | Role-based access control (Guide / Assistant) · Real-time communication · Payment processing via Stripe · Interactive maps · Cloudinary media pipeline · Full CRUD for tours, bookings, reviews, employees |

### 🎨 [Quantipixor](https://github.com/ByteCrister/quantipixor)
**Privacy-first, browser-based image processing suite**

A full-featured image tool that runs **core operations entirely client-side** — your images never leave your device. Includes batch compression, format conversion, resizing, background removal, OCR, favicon generation, and developer mock-data utilities.

| | |
|---|---|
| **Live** | [quantipixor.vercel.app](https://quantipixor.vercel.app) |
| **Stack** | Next.js 16 · React 19 · TypeScript · Canvas API · JSZip · shadcn/ui · Zustand · FastAPI (background removal microservice) |
| **Highlights** | SHA-256 deduplication · Batch processing (up to 50 images) · ZIP download · Glassmorphism UI · Hybrid client + server processing model |

| | |
|---|---|

| **Highlights** | Infinite scroll feed · Real-time 1:1 chat + presence detection · WebRTC video calls · AI meeting recommendations · Timezone-aware slot creation · Rate limiting with Redis |
